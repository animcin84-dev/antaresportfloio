# ABAI BOL — Awwwards Submission Pack / V7

## Submission title

**ABAI BOL — Engineering Memory**

## Short description

ABAI BOL is an FTC robotics team from Almaty, Kazakhstan, formerly ANTARES. Engineering Memory turns the team's real robot, CAD, competition and award archive into one continuous machine-memory story: every machine carries the decisions of the one before it.

## Long description

V7 removes the portfolio/gallery feeling and directs the homepage as eight connected chapters. A Spline machine appears as an Almaty signal; ANTARES transitions into ABAI BOL without erasing the team's history; four years of memory lead into one shared Machine inspection surface built from supplied robot/CAD imagery. The Indonesia mission becomes a single photographic reward, followed by a Flight Recorder that merges year navigation with the supplied competition record. People and a quiet magenta transmission close the experience.

A single chapter-aware SVG **Memory Spine** crosses the whole site and changes meaning from signal, to identity continuity, to timeline, engineering callout, route, record trajectory, people connection and final transmission. Motion is deliberately budgeted: Flight Recorder is the only long scroll lock, while the hero remains a shorter cinematic story and Mission is not pinned as a second lock.

## Suggested judging strengths

- **Design:** current-magenta vs legacy-red identity, restrained editorial typography, one continuous Memory Spine.
- **Usability:** eight-destination text index, keyboard year controls, manual Flight Recorder controls, reduced-motion parity, off-canvas archive.
- **Creativity:** Memory Spine, Machine inspection, one-image Mission and merged Flight Recorder rather than a generic award/gallery stack.
- **Content:** supplied robot/CAD/event media, preserved 18-distinction record, evidence-source access.
- **Developer:** delayed Spline path, low/reduced fallback, semantic DOM images, responsive variants, code-split Flight Recorder, focus traps and deterministic quality mode.
