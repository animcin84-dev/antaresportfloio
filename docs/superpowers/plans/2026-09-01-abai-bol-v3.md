# ABAI BOL V3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the V2 iframe/dark orbit experience with an evidence-led ABAI BOL V3 using the supplied GLB, real team media, pinned scroll storytelling, and a verified performance/accessibility QA pipeline.

**Architecture:** Keep React/Vite and make GSAP ScrollTrigger the primary scroll director. Render the supplied Nexbot GLB directly through React Three Fiber, keep DOM content semantic, use WebGL only as a visual layer, and code-split heavy scenes. Mission Orbit becomes a scroll-driven state machine with four season stops rather than autonomous rotation.

**Tech Stack:** React 19, Vite, GSAP + ScrollTrigger + @gsap/react, React Three Fiber, Drei, Three.js, Lenis, maath, @use-gesture/react, @react-three/postprocessing, Playwright.

**Spec:** `docs/V3_SPEC.md`

## Global Constraints
- Public name: ABAI BOL.
- Preserve ANTARES as the prior identity of the same team.
- Use the user-supplied `nexbot_robot_character_concept.glb`; do not require paid Spline export.
- Use the real uploaded photos and logos.
- Do not represent the Nexbot presentation character as the FTC competition robot.
- Mission Orbit must be bright/readable and pinned through all four states.
- Preserve native scrolling; no wheel/touch trapping.
- Honor `prefers-reduced-motion`.
- Mobile must not rely on hover.
- Build/test/screenshot verification is mandatory before merge.
