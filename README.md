# ABAI BOL — FTC Robotics Portfolio

Award-oriented portfolio website for **ABAI BOL**, the same Almaty robotics team formerly known as **ANTARES**.

This repository is intentionally separate from the earlier Awwwardsportfolio repository.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:5173`.

## Production build

```bash
npm run build
npm run preview
```

## Creative-development references used

The final implementation is original, but its interaction architecture was informed by the source packs provided for this project, including Codrops cinematic scroll/WebGL examples, BraveBot robotics presentation patterns, shader libraries, GSAP UI, Motion Primitives, R3F/Drei, Showcase Images, Aetheris UI, Curtains.js and related uploaded reference repositories.

No demo branding or stock imagery from those repositories is shipped here.
